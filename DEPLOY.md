# Публикация AI Sana Hub

## Созданный сервис (29 сентября 2026)

- Сайт: https://ai-sana-hub.onrender.com/ — статус Live; главная, вход и `/api/health` отвечают HTTP 200.
- Панель: https://dashboard.render.com/web/srv-datqlp093c1s73blgfbg
- Источник: https://github.com/BAITC-Hacks/hack-20bdc7a0-oslaebs
- Коммит: `d99ebb5dd057543f3f887252c2960978f0fb3108`
- Тариф: Free; Python 3.12.10; проверка здоровья: `/api/health`.
- По просьбе владельца первый запуск использует временную SQLite, без Supabase.
  Данные могут теряться при перезапуске или новом деплое.
- `AUTH_SECRET` сгенерирован и хранится в окружении Render.
- AI-ключ не перенесён: AI работает в демо-режиме.

Архивный репозиторий содержит папки с искажёнными именами. Команда сборки
копирует сервер и изображения в корректные каталоги, исключая старую базу:

```sh
pip install -r requirements.txt && python -c 'from pathlib import Path; import shutil; root=Path("."); [shutil.copytree(next(p for p in root.iterdir() if p.is_dir() and p.name.startswith(name) and p.name!=name), root/name, ignore=shutil.ignore_patterns("data", "__pycache__", ".env"), dirs_exist_ok=True) for name in ("backend", "assets")]'
```

Запуск: `python -m uvicorn backend.main:app --host 0.0.0.0 --port $PORT`.
Локальные исходники совпадают с сервером и страницами указанного коммита.
Локальные изменения автоматически в архивный репозиторий не попадают.

## Вариант с постоянной базой

Подготовлен `render.yaml` для размещения FastAPI и браузерных страниц
одним сервисом на Render. Публичный адрес появится после успешного деплоя.

1. Загрузите проект в свой GitHub-репозиторий. Репозиторий может быть приватным:
   доступность сайта не зависит от публичности исходников. Не загружайте `.env`,
   `.venv` и `backend/data` — они уже исключены через `.gitignore`.
2. Создайте проект Supabase и выполните `backend/supabase/schema.sql` в SQL Editor.
   Если используете существующий проект, сначала убедитесь, что схема применена.
3. В Render выберите **New → Blueprint**, подключите репозиторий и укажите
   `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` в запрошенных полях.
   Ключ service_role хранится только в окружении сервера.
4. Запустите Blueprint. После успешного деплоя откройте адрес сервиса из Render.
   Проверьте главную страницу, `/login` и `/api/health`, затем регистрацию,
   публикацию задачи и отклик из другого аккаунта.
5. Для живого AI добавьте в окружение Render `AI_PROVIDER`, `AI_API_KEY`
   и `AI_MODEL` из своих настроек. Без ключа доступен локальный демо-режим AI.
   Укажите `APP_PUBLIC_URL`, равный полученному публичному адресу.

AUTH_SECRET генерируется Blueprint автоматически. Локальная база SQLite
не переносится: новый проект Supabase начнёт с пустой базы.
Не оставляйте Supabase ненастроенным: файловая система бесплатного сервиса
Render не сохраняет SQLite после перезапуска или нового деплоя.
Бесплатный сервис также может засыпать при отсутствии запросов.

В `privacy.html` пока находится шаблон: заполните данные оператора,
контакт и сроки хранения перед сбором данных реальных участников.
Не задавайте ADMIN_EMAIL для непроверенного адреса: подтверждение почты
в текущем MVP отключено.

Документация: https://render.com/docs/blueprint-spec и https://render.com/docs/free.
